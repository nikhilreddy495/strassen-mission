THE PROBLEM

Classical multiplication: 8 products for 2×2

For C = A × B, every entry is a row-times-column sum. For n×n matrices that is n² entries, each needing n multiplications, so n³ in total.

C11 = A11·B11 + A12·B21
C12 = A11·B12 + A12·B22
C21 = A21·B11 + A22·B21
C22 = A21·B12 + A22·B22
→ 8 multiplications, 4 additions

Question Strassen asked: can we cheat and use only 7 products, even if we do more additions?

THE IDEA

Split into blocks, recurse

Cut each n×n matrix into four (n/2)×(n/2) blocks. Treat blocks like numbers. Classical block multiplication makes 8 recursive calls: T(n) = 8T(n/2) + Θ(n²) = Θ(n³). No gain.

Strassen's trick: build the same four answer blocks from just 7 recursive multiplications, by multiplying clever sums and differences of blocks. Matrix additions cost only Θ(n²), so they are cheap.

Why it works

Multiplication is the expensive step (it recurses). Addition is not. Trade one multiplication for extra additions and the whole recurrence changes.
THE SEVEN PRODUCTS

Strassen's formulas

M1 = (A11 + A22)(B11 + B22)
M2 = (A21 + A22) B11
M3 = A11 (B12 − B22)
M4 = A22 (B21 − B11)
M5 = (A11 + A12) B22
M6 = (A21 − A11)(B11 + B12)
M7 = (A12 − A22)(B21 + B22)
Rebuild the answer:
C11 = M1 + M4 − M5 + M7
C12 = M3 + M5
C21 = M2 + M4
C22 = M1 − M2 + M3 + M6

THE MATHS

Recurrence and Master Theorem

T(n) = 7·T(n/2) + Θ(n²)
a = 7, b = 2, f(n) = n²
log₂7 ≈ 2.807 > 2 → Case 1
T(n) = Θ(n^log₂7) ≈ Θ(n^2.81)

Compare with classical: T(n) = 8T(n/2) + Θ(n²) gives log₂8 = 3, so Θ(n³). Dropping from 8 calls to 7 lowers the exponent from 3 to about 2.81.

Think about it

Every level of recursion keeps only 7/8 of the multiplications. After log₂n levels the saving compounds to (7/8)log₂n.

REALITY CHECK

So why isn't Strassen used everywhere?

Overhead

18 extra matrix additions per level and temporary storage. Small matrices run faster with the classical method.

Cut-off

Practical code recurses until blocks are small (a tuned threshold), then switches to classical loops.

Numerical stability

With floating point, Strassen's error bounds are weaker than classical. Fine for many uses, risky for some.

Not the end

Later algorithms (Coppersmith–Winograd and successors) push the exponent lower, but are mostly theoretical.
